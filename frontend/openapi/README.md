# openapi

The backend's OpenAPI schema (generated by drf-spectacular) is the contract.

- Live schema (dev): `http://localhost/api/schema/` (Nginx) or `http://nginx/api/schema/` (inside Docker)
- Swagger UI (dev): `http://localhost/api/docs/`
- Generate types: `npm run api:types` (writes `src/types/api.d.ts`, commit the result)
- CI drift check: `npm run api:check` regenerates and fails on any difference

`src/types/api.d.ts` is generated and never edited by hand. Until the first generation it is a
permissive placeholder, so paths are not yet checked by the compiler.
